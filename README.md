🚀 Highlighted Work

MCP Tool Selection & Context-Window Optimization — UNCW Research
Designed a hybrid multi-signal tool ranking system (lexical retrieval, bi-encoder embeddings, verb alignment, solvability scoring, fused via Reciprocal Rank Fusion) achieving a 77% reduction in token usage while maintaining full tool coverage. Built an evaluation framework spanning 33 live MCP servers and 56+ tasks with a 6-dimensional LLM-as-judge scoring pipeline.

AutoML Pipeline
Automated training and tuning across 9 classifiers for tabular datasets, improving accuracy by 30% and F1/ROC-AUC by 20% over traditional grid search. Built with NumPy/Pandas for preprocessing and Streamlit for result visualization.

NLP Sentiment Classifier
Compared TF-IDF vs. transformer embeddings for sentiment classification (85% vs. 78% accuracy), with a full pipeline for preprocessing, feature engineering, training, and error analysis.
