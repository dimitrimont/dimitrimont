## Selected work

**[MCP tool ranking](https://dimitri-montgomery-site.pages.dev/research/mcp-ranking/)** · research, UNCW<br />
When an agent can reach hundreds of tools, which few should it see? I wrote the first word-matching
and solvability rankers, and most of the harness that runs agents against live MCP servers with an
LLM judge. The results stay with the team until the paper.

**[CampusLinkHub](https://dimitri-montgomery-site.pages.dev/campuslinked/)** · React Native, Next.js, Supabase<br />
A campus marketplace and study app on phones and the web from one pnpm monorepo. Row-level security
on every table, Stripe Connect payments, and 11 Claude features behind one edge function, covered by
1,478 Jest tests.

**[Atlas](https://dimitri-montgomery-site.pages.dev/atlas/)** · Python, FastAPI, Swift<br />
A self-hosted home platform: a file server on a Raspberry Pi that proves its backups restore, and a
face-recognition door camera, both behind one shared contract.

**[Malware similarity](https://dimitri-montgomery-site.pages.dev/ml/malware-similarity/)** · [code](https://github.com/dimitrimont/AI-LSH-Malware-Detection)<br />
Finds malware that behaves alike by translating it into English and letting locality-sensitive
hashing pick the pairs to compare. On 4,000 descriptions it took 55% of the time of comparing every
pair and found 96% of the related ones.

**[Intrusion detection](https://dimitri-montgomery-site.pages.dev/ml/intrusion-detection/)** · [code](https://github.com/dimitrimont/cyber363-intrusion-detection)<br />
Five models on NSL-KDD. Choosing the alarm threshold on held-out traffic took the random forest from
60.5% to 90.0% of attacks caught, and 87.5% of attack types it had never seen, at 9.9% false alarms.

**[AnyField Dictation](https://dimitri-montgomery-site.pages.dev/projects/anyfield-dictation/)** · [code](https://github.com/dimitrimont/anyfield-dictation)<br />
A Chrome extension that types what you say into any text box, with a Whisper model running on your
own device: 13.1% word error rate on FLEURS English.

**More:** a [sentiment classifier](https://dimitri-montgomery-site.pages.dev/ml/nlp-sentiment/)
where DistilBERT reached 87.5% once it could read the end of each review,
[AutoML for tabular data](https://dimitri-montgomery-site.pages.dev/ml/automl-tabular/),
[hurricane impact](https://dimitri-montgomery-site.pages.dev/ml/hurricane-impact/) for Wilmington,
and [computer vision written by hand](https://dimitri-montgomery-site.pages.dev/vision/): panorama
stitching, optical flow, Harris corners and image rotation.
